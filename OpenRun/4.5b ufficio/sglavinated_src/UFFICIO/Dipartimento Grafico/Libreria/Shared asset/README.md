# Shared asset

Solo il Designer può approvare o aggiornare gli asset condivisi per la produzione. Builder/Developer e Developer/Builder Junior li leggono e li usano senza sovrascriverli o crearne copie modificate. Ogni elemento pubblicato deve avere stato approvato, licenza e provenienza verificabili.

**Stato verificato 2026-10-18:** non contiene ancora file asset; questa cartella contiene solo questo README. Consultare [l'inventario grafico](../CATALOGO_RISORSE.md) per lo stato effettivo dei materiali e i percorsi sorgente correnti.

Nella fase corrente il catalogo attivo e i relativi asset restano in `../../../../assets_originali/`; non duplicare qui gli asset finché la migrazione della produzione non è stata completata. La presenza nel catalogo sorgente non significa che un file sia già stato pubblicato nella Shared asset 4.6.
