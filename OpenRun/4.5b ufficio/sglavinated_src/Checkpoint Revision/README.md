# Checkpoint Revision

Area protetta per checkpoint e revisioni combinate destinate ad Andrea. Scrittura esclusiva del Capo; gli altri ruoli consegnano le proprie review nei percorsi assegnati.

Un checkpoint resta aperto finché mancano una review indipendente, una prova di build/test o una decisione di Andrea. Nessuna revisione registra come approvata una decisione non ancora presa da Andrea.
